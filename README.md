# NArFU 111621 实时课表读取后台（待部署）

课表网页保持原网址：https://narfu-timetable-111621.github.io/

此仓库仅准备后台服务；不能把 GitHub 仓库地址当作已经运行的 API。

每次 `/api/timetable` 独立请求重新获取学校公开课表，解析课程时间、教师和教室，并返回中俄双语。只合并同时进行的学校请求，没有返回旧课表的成功降级。学校失败时返回 502/504，由网页保留旧数据并提示失败。

无需访问令牌或用户登录。接口只读取固定班级，允许原 GitHub Pages 网址跨站访问，不接受任意代理网址。

## 免费部署准备

在自己的 Vercel 账户使用 Hobby 免费方案导入此公开仓库，项目名称使用 `narfu-live-111621` 等不含个人名称的名称，根目录保持仓库根目录，Framework 选 Other，输出目录由 vercel.json 指定为 public。不要开通 Pro 或付费试用。此服务没有定时任务和数据库；学校数据按网页请求读取。

部署后先核验公开 API 及俄罗斯当地可达性，再将实际 API 地址连接到原课表网页。当前原网站尚未切换到本服务。

## 验证

Node.js 22：`npm test` 验证改课后再次抓取、失败状态、请求合并、跨站访问和固定来源；`npm run check-school` 连接学校读取真实课表。没有第三方依赖。
