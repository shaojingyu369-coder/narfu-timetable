# NArFU 111621 实时课表读取后台

课表网页：https://narfu-timetable-111621.github.io/

公开后台：https://narfu-live-111621.vercel.app/api/timetable

每次独立请求重新获取学校公开课表，解析课程时间、教师和教室，返回中俄双语。只合并同时进行的请求，不用旧课表冒充实时结果。学校读取失败返回 502/504，由网页保留已有数据并提示失败。

无需学生登录或访问令牌，只读取固定班级，允许原 GitHub Pages 网址跨站访问，不接受任意代理网址。

## 托管

已使用 Vercel Hobby 免费方案部署，项目名称 narfu-live-111621。公开地址不含个人账号名。没有开通 Pro 或付费试用。

当前通过 Drop to Deploy 上传文件部署，没有关联 Git 自动部署；修改本仓库不会自动更新运行中的后台。后续后台代码变动需要重新上传到同一个 Vercel 项目或另行配置 Git 部署。网站前端仍通过原组织仓库的 GitHub Actions 发布。

服务没有定时任务和数据库：网页打开时、前台定时检查、手动点击都会请求后台重新读取学校。网页关闭期间没有额外轮询。免费用量超限可能暂停服务，俄罗斯当地访问需实际测试。

## 验证

Node.js 22：`npm test` 验证改课后再次抓取、失败状态、请求合并、跨站访问和固定来源；`npm run check-school` 连接学校读取真实课表。没有第三方依赖。
